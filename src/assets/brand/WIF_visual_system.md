# When Intelligence Is Free — Public Visual System

## Brand asset
- Every public visual carries the canonical WIF lighthouse + wordmark.
- Always overlay the exact transparent PNG after image generation. Never ask an image model to redraw it.
- Light background: `WIF_brandmark_transparent_dark.png`
- Dark / photographic background: `WIF_brandmark_transparent_reverse.png`
- Do not distort, recolor, rewrite, crop, or reconstruct the brand mark.
- Default placement: bottom-left with clear space. Move only when content makes that impossible.
- Keep the mark visually secondary to the essay title / analytical content.

## Output formats
- Substack cover: 1200 × 630 px, full bleed.
- LinkedIn native image: 1080 × 1350 px (4:5), full bleed.
- Inline essay illustration: standalone image, normally landscape, at least 1600 px wide.

## Covers
- One strong visual metaphor; no collage unless specifically requested.
- Rich, cinematic colour is acceptable and preferred when it fits the argument.
- No white canvas margins.
- Substack and LinkedIn use the same visual language but are composed separately for their aspect ratios; never just paste/crop one into the other.
- Title large; dek short; keep copy off visually busy areas.
- Canonical WIF brand asset always present.

## Analytical illustrations
- Editorial research graphic, not PowerPoint.
- No slide numbers before titles.
- No subtitle that merely repeats the diagram.
- One main mechanism per image.
- Prefer simple path / ladder / river / calendar / handoff structures over dense networks.
- Minimal explanatory text; the essay carries the detail.
- Default visual language: white/off-white field, navy typography, restrained blue / green / amber / red.
- Normal publication margins; no excessive empty space.
- Each illustration is generated/exported separately, never as a multi-panel presentation board.

## Footers
- Footer only when it states the one conclusion the reader should remember.
- Use the same restrained full-width footer treatment across an essay's illustration set.
- No trailing period.
- Do not add a footer just to fill space.

## Evidence discipline
- Concept visuals must not imply fake precision.
- Quantitative charts use verified data and appropriate source treatment.
- Do not visually present imperfect comparisons as exact apples-to-apples equivalents.
- Company names are evidence; avoid decorative logo walls.
